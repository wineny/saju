# 채점 기준 — 이 도구가 채택한 것

명리는 유파마다 기준이 갈린다. 이 문서는 **이 도구가 무엇을 근거로 점수를 매기는지**를 못박아
둔 것이다. 기준을 바꾸고 싶으면 여기를 고치고 `lib/engine.cjs` 의 `score()` 를 같이 고쳐라.
**한쪽만 고치면 어긋난다.**

## 전제 — 이 점수가 하는 일과 안 하는 일

- **하는 일**: 후보 명식들을 같은 잣대로 줄 세워 "덜 치우친 쪽"을 고른다. **상대 비교값**이다.
- **안 하는 일**: 절대적 길흉 판정, 아이의 미래 예측, 특정 날짜의 "합격" 판정.
- 90점과 85점의 차이는 유의미하지 않다. **90점대와 60점대의 차이**를 보라.

## 배점 (총 100점)

| 항목 | 배점 | 근거 |
|---|---:|---|
| 오행 균형 | 28 | 없는 오행이 있으면 그 기운을 평생 빌려 쓴다고 본다. 편중도(표준편차)와 결손 오행 수로 감점 |
| 형·충·파·해 | 20 | 지지끼리 부딪히는 관계. 20점에서 감점 방식 |
| 일간 중화 | 14 | 일간이 태과·태약하면 그릇이 한쪽으로 쏠린다고 본다. 비겁+인성 세력이 전체의 **45%** 일 때 만점 |
| 일주 (십이운성) | 10 | 일간이 일지에서 갖는 힘. 뿌리(통근)가 튼튼한 일주를 높게 본다 |
| 합 | 7 | 육합·삼합·천간합. 기운이 뭉쳐 흐르는 것으로 보아 가점 |
| 상생 흐름 | 7 | 인접 기둥 천간끼리의 생. **일간을 생해주는** 흐름을 가장 높게 본다 |
| 십신 균형 | 4 | 한 십신이 4개 이상 몰리면 감점 |
| (선택) 상대·부모 궁합 | 10 | 상대 사주를 준 경우에만. 미입력 시 90점 만점을 100점으로 정규화 |

### 일주 (십이운성) 10점

다른 택일 도구들이 쓰는 "일주 길흉 60갑자 등급표"에 대응하는 항목이다.
출처를 알 수 없는 등급표를 베끼는 대신, **일간이 일지에서 갖는 십이운성**으로 뿌리를 잰다.
양간은 순행, 음간은 역행한다.

| 단계 | 점수 | | 단계 | 점수 |
|---|---:|---|---|---:|
| 제왕 | 10 | | 태·쇠 | 5 |
| 건록 | 9.5 | | 병 | 3.5 |
| 관대·장생 | 8 | | 사·묘 | 3 |
| 양 | 6.5 | | 절 | 2 |
| 목욕 | 5.5 | | | |

⚠ 여기서는 **일주 자체의 힘만** 본다. 일간이 강한 게 곧 좋은 사주라는 뜻은 아니며,
과다 여부는 별도 항목인 "일간 중화"가 잡는다.

### 상생 흐름 7점

| 관계 | 가점 |
|---|---:|
| 월간이 일간을 생함 | +3 |
| 시간이 일간을 생함 | +3 |
| 년간 → 월간 상생 | +1.5 |
| 일간이 월간·시간을 생함 (설기) | 각 +0.8 |

일간이 남을 생하는 건 기운이 새는 것으로 보아 낮게 준다.

### 오행 세력 가중치

- 천간 4글자: 각 **1.0**
- 지지 본기: 각 **1.0**
- 지장간 중기·여기: 각 **0.4**

### 형·충·파·해 감점

기본 감점에 **위치 가중**을 곱한다.

- 붙어 있는 기둥(년월, 월일, 일시)끼리면 **×1.0**, 떨어져 있으면 **×0.6**
- **일주 또는 시주**가 걸리면 **×1.4** — 일주는 본인, 시주는 말년·자식 자리라 더 무겁게 본다

| 관계 | 기본 감점 |
|---|---:|
| 육충 (자오·축미·인신·묘유·진술·사해) | 6 |
| 삼형 (인사신 / 축술미, 세 글자 모두) | 8 |
| 무례지형 (자묘) | 3 |
| 자형 (진진·오오·유유·해해) | 3 |
| 육해 | 2.5 |
| 원진 | 2 |
| 육파 | 1.5 |
| 천간충 (붙어 있을 때만) | 2 |

### 합 가점 (최대 10)

| 관계 | 가점 |
|---|---:|
| 삼합 완성 (신자진·해묘미·인오술·사유축) | 5 |
| 육합 | 2.5 |
| 천간합 (붙어 있을 때만) | 2 |
| 반합 | 1.5 |

### 부모 궁합 (기본 5점에서 가감)

| 관계 | 점수 |
|---|---:|
| 부모 일간과 아이 일간이 합 | +2.5 |
| 부모 일간이 아이 일간을 생함 | +1.5 |
| **아이가 부모를 생함** (효도로 보는 해석과 기운이 샌다는 해석이 갈려 절반) | +0.8 |
| 부모 일지와 아이 일지가 육합 | +1.5 |
| 부모 일지와 아이 일지가 충 | **−3** |
| 부모 일간과 아이 일간이 충 | **−2** |
| **부모와 아이 일간이 상극** (방향 무관) | **−1** |

**띠(년지) 궁합은 일부러 안 본다.** 다른 도구들이 "띠 육합 100점" 같은 배점을 주는데,
같은 해에 태어나는 아이는 전부 같은 점수를 받으므로 **날짜를 고르는 데 변별력이 0이다.**

## 시간대 처리 — 여기가 제일 틀리기 쉽다

### 1. 절기(년주·월주)는 북경시로 환산해서 판정한다

`lunar-javascript` 는 중국 라이브러리라 **절기 시각을 북경시(UTC+8)로 계산한다.**

검증한 값:

| 절기 | 라이브러리 | 한국천문연구원 (KST) |
|---|---|---|
| 2027 입춘 | 02-04 09:46 | 02-04 **10:46** |
| 2027 우수 | 02-19 05:33 | 02-19 **06:33** |

정확히 1시간 차이다. 그래서 년주·월주를 뽑을 땐 KST 에서 **60분을 빼서** 넣는다.
보정하지 않으면 2027-02-04 09:47~10:46 에 태어난 아이의 **월주가 통째로 틀린다.**

절기는 천문 현상이라 그 순간이 지구 어디서나 동일하다. 그래서 절기 판정에는
**진태양시를 쓰지 않고 표준시로 비교한다.**

### 2. 시주는 진태양시로 판정한다

한국 표준시는 동경 135° 기준인데 서울은 126.978° 다. 차이만큼 시계가 실제 태양보다 앞선다.

```
보정(분) = (경도 − 135) × 4        서울 → −32분
```

즉 **시계로 09:32 가 진태양시 09:00** 이고, 여기서 巳시가 시작한다.
출력의 시각 구간은 이 보정을 반영한 **실제 경계**다 (`09:32~11:31` 같은 어중간한 값이 정상).

주요 도시 경도: 서울 126.978 · 부산 129.075 · 대구 128.601 · 광주 126.851 · 대전 127.385 · 제주 126.531

### 3. 야자시는 다루지 않는다

23시 이후 출생을 다음 날로 넘길지(야자시/조자시)는 유파가 갈린다.
**이 도구는 이 문제를 건드리지 않는다.** 낮 시각을 고르는 용도로 만들었기 때문이다.
밤 시각을 검토해야 한다면 이 도구의 결과를 쓰지 마라.

## 이 도구가 일부러 안 하는 것

- **신살(神煞)** — 유파별 편차가 너무 크고, 같은 신살도 길흉 해석이 정반대인 경우가 많다
- **용신 판정** — 격국·조후·억부 중 무엇을 쓰느냐로 결론이 갈린다. 일간 중화도로 대신했다
- **수명·중병·사고·이혼·파산** — 판정하지 않는다. 도구의 정확도와 무관하게 해선 안 되는 일이다
- **대운·세운** — 택일 시점에는 판단 근거로 쓰기 어렵다
- **날짜의 절대적 길흉(손없는 날 등)** — 사주 명식과 별개 체계다
